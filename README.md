# Fibonacci Python Program

## Project Description

This project contains a Python program that generates and displays the Fibonacci series for a user-specified number of terms.

The program uses a `for` loop and variable updates to generate the sequence.

## Features

- Takes the number of terms as input from the user.
- Generates the Fibonacci series starting from 0 and 1.
- Uses a `for` loop to generate the requested number of terms.
- Displays the series on the screen.

## Requirements

- Python 3.x

## Usage

1. Make sure Python 3 is installed.
2. Save the program as `fibonacci.py`.
3. Open a terminal in the folder containing the file.
4. Run the program using:

```bash
python fibonacci.py
```

5. Enter the number of terms when prompted.

## Example

```text
Enter the number of terms: 5
Fibonacci series:
0 1 1 2 3
```

## Notes

The program does not include explicit validation for negative input or non-integer input.
